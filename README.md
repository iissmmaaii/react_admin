# CypherVault Admin Dashboard

لوحة إدارة ويب خاصة بمنصة **CypherVault** للخدمات المصرفية الرقمية مبنية باستخدام React وTypeScript وVite.

تتصل لوحة الإدارة بالخدمات الخلفية لمنصة CypherVault من خلال بوابة API Gateway المؤمنة وتوفر واجهات لإدارة المستخدمين والحسابات والوثائق والتحويلات والإشعارات ومحادثات الدعم.

## الميزات الرئيسة

- تسجيل دخول المسؤول وإدارة الجلسة.
- إدارة المستخدمين وبيانات الهوية.
- عرض الحسابات المصرفية ومراقبتها.
- متابعة التحويلات والمعاملات المالية.
- مراجعة وثائق العملاء وطلبات التحقق.
- عرض الإشعارات ومتابعة حالتها.
- عرض محادثات الدعم.
- التكامل مع الخدمات الخلفية عبر API Gateway.
- واجهة إدارية منظمة ومتجاوبة.

## التقنيات المستخدمة

- React
- TypeScript
- Vite
- REST APIs
- JWT Authentication
- HTML
- CSS

## بنية المشروع

يقسم المشروع وفق بنية Clean Architecture عملية:

~~~text
src/
├── app/
├── application/
├── core/
├── domain/
├── infrastructure/
└── presentation/
~~~

### Domain

تحتوي هذه الطبقة على الكيانات الأساسية وعقود المستودعات.

### Application

تحتوي على حالات الاستخدام وتنسيق خطوات العمل داخل التطبيق.

### Infrastructure

تحتوي على تنفيذ طلبات HTTP ومستودعات البيانات والتكامل مع الخدمات الخلفية.

### Presentation

تحتوي على الصفحات والمكونات والتخطيطات ومنطق واجهة المستخدم.

### App

تحتوي على التوجيه وموفرات التطبيق وإعدادات بدء التشغيل.

### Core

تحتوي على الإعدادات المشتركة وتخزين JWT وHTTP Client وأدوات التنسيق.

## المتطلبات

يجب تثبيت البرامج التالية قبل تشغيل المشروع:

- Node.js 18 أو إصدار أحدث.
- npm.

## إعداد الاتصال بالخدمات الخلفية

أنشئ ملف البيئة المحلي اعتمادا على الملف النموذجي:

~~~powershell
Copy-Item .env.example .env
~~~

عنوان API Gateway الافتراضي:

~~~env
VITE_API_BASE_URL=http://localhost:8080
~~~

لا يجوز رفع ملف `.env` أو `.env.local` إلى المستودع.

## التشغيل على Windows PowerShell

افتح PowerShell داخل مجلد المشروع ثم نفذ:

~~~powershell
Set-ExecutionPolicy -Scope Process Bypass
.\START_REACT_ADMIN.ps1
~~~

يمكن أيضا تشغيل المشروع يدويا:

~~~powershell
npm install
npm run dev
~~~

بعد تشغيل المشروع افتح العنوان التالي:

~~~text
http://localhost:5173
~~~

يشترط تصميم المشروع تشفير رسائل الدعم بعد تسليمها إلى الإدارة. ولأن لوحة الويب لا تمتلك مفتاح التشفير الخاص تعرض صفحة الدعم في هذه النسخة المحادثات والرسائل فقط ولا ترسل رسائل بنص واضح يخالف تصميم الأمان.
